# Sranga Tech Blog

Public technology blog from **Sranga Limited**, covering DevOps, cloud, infrastructure, data engineering and interview preparation.

## Run locally

Open `index.html` in a browser or serve the directory using any static web server.

## Publishing

The site is designed for GitHub Pages. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Content policy

Free articles and sample questions may be stored here. Paid question-bank answers must be hosted separately behind authenticated access and must not be committed to this public repository.
