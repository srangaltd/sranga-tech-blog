# Sranga Tech Blog

Public **STAR-based technology interview preparation** blog from **Sranga Limited**, with practical scenarios and guidance for DevOps, Cloud and Data professionals.

## Run locally

Open `index.html` in a browser or serve the directory using any static web server.

## Publishing

The site is designed for GitHub Pages. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Content policy

Free articles and sample questions may be stored here. Paid question-bank answers must be hosted separately behind authenticated access and must not be committed to this public repository.

The public interview-preparation page contains three sample answers in each of eight subject areas. One complete subject bank is NZ$10, one-hour coaching is NZ$40, and one selected bank plus coaching is NZ$45. Paid answers remain outside this public repository; payment instructions and Google Meet invitations are confirmed privately by email.
