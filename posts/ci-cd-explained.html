CI/CD explained without the jargon

Continuous integration checks every proposed code change. Continuous delivery keeps a tested change ready to release. Continuous deployment goes one step further and releases successful changes automatically.

A typical pipeline

  1. A developer pushes a change.
  2. Automated checks validate formatting, tests and security rules.
  3. The application is built into a deployable artifact.
  4. The artifact moves through controlled environments.
  5. Monitoring confirms the release is healthy.
